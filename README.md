# captain-flip-hot-seat-two-players
A 2-players hotseat demo for the board game Captain Flip, in Chinese. 
# 航海争夺 规则说明

## 游戏概览
航海争夺是一款双人热座对战游戏。两位玩家各自持有一张相同的地图（共6种可选），轮流从公共牌堆抽取双面角色方块，放置到自己的地图上。每填满一列会触发该列的柱奖励。游戏结束时，总分最高且未“爆掉”的玩家获胜。

## 游戏组件
- **角色方块**：共72个双面方块。每个方块的两面各印有一种角色。角色共有9种，两两组合共有36种不同方块，每种各2个。开局时洗混，正反面随机。
- **地图**：共有A、B、C、D、E、G六种地图（没有F）。每张地图包含5列，每列有若干连续格子，部分列拥有柱奖励。
- **藏宝图标记**：全游戏只有一张藏宝图，开局不属于任何玩家。
- **囚徒格**（仅地图G）：额外存在，不属于地图行列。

## 角色介绍
- **厨师**：放置后立即得分，得分数等于其所在行已放置的方块数量（包括自身）。
- **鹦鹉**：放置后立即触发一次额外抽板（相当于立即再进行一个回合）。游戏结束时，每只鹦鹉扣1分。
- **制图师**：放置后立即获得藏宝图。
- **领航员**：放置后立即获得分数，分值为自己地图上面朝上的制图师数量×2。
- **炮手**：放置后立即获得5分。游戏结束时，若己方地图上面朝上的炮手数量达到3个或以上，该玩家“爆掉”并直接输掉游戏（双方都爆掉则平局）。
- **猴子**：放置后立即获得1分，并且必须将其上下左右相邻的一个已放置方块翻面（若存在可翻的方块则必须翻一个）。
- **瞭望员**：游戏结束时，若其上方没有放置任何方块，则获得4分。
- **木匠**：游戏结束时，若其所在行和列均没有炮手，则获得3分。
- **水手**：游戏结束时，统计有水手的列数量n，所有水手合计获得n²分。

## 地图与柱奖励
每张地图有5列，编号从左到右为第1至第5列。当某列被填满时，立即触发该列的柱奖励（若有）。柱奖励效果分为立即结算和游戏结束结算两类。

### 地图A
- **第1列**：无柱奖励
- **第2列**：立即获得藏宝图
- **第3列**：立即得5分
- **第4列**：无柱奖励
- **第5列**：立即得3分

### 地图B
所有柱奖励均为“先完成者得高分为先，后完成者得低分”。
- **第1列**：先完成者1分，后完成者0分
- **第2列**：先完成者2分，后完成者1分
- **第3列**：先完成者6分，后完成者3分
- **第4列**：先完成者0分，后完成者2分
- **第5列**：先完成者4分，后完成者2分

### 地图C
- **第1列**：立即获得藏宝图
- **第2列**：游戏结束时，若此列所有角色相同，得6分
- **第3列**：无柱奖励
- **第4列**：游戏结束时，若此列所有角色互不相同，得4分
- **第5列**：无柱奖励

### 地图D
- **第1列**：立即得3分
- **第2列**：立即得2×已完成列数（包括当前列）
- **第3列**：立即得1×此列不同角色种类数
- **第4列**：无柱奖励
- **第5列**：立即失去1分。若当前分数为0，则不可选择此列放置。

### 地图E
- **第1列**：立即得4分
- **第2列**：若此列两格角色相同，立即获得藏宝图
- **第3列**：若此列三个角色互不相同，立即选择一个已放置的方块翻面
- **第4列**：若此列三个角色相同，立即额外抽一板（如同执行新回合）
- **第5列**：立即得3分

### 地图G
开局时，每名玩家各抽2个方块作为自己的囚徒，放置于自己的囚徒格内（囚徒格不属于地图任何行列，正面可见但不触发效果）。
- **第1列**：立即将自己一个囚徒翻面（不触发效果，若无囚徒则无效果）
- **第2列**：立即获得藏宝图
- **第3列**：先完成者立即5分，后完成者立即2分
- **第4列**：立即释放一个自己的囚徒并放置（不能翻面）
- **第5列**：立即释放一个自己的囚徒并放置（不能翻面）

## 回合流程
玩家轮流进行回合。玩家1先手，玩家2后手。

### 抽牌与翻面
1. 从公共牌堆抽一个方块，查看其当前正面角色。
2. 玩家可以决定是否翻面。若翻面，则正面对调，翻面后不可立即再翻回；若不翻面，则直接使用当前正面。
3. 翻面或决定保持正面后，玩家进入放置步骤。

### 放置
- 将当前方块放置到任意一个未填满的列中，放在该列最下方的空格。
- 如果没有任何合法空格可放，则弃掉该方块。
- 放置后，立即结算该方块当前面朝上的角色的效果（若有）。

### 柱奖励
- 当某列被填满时，立即触发该列柱奖励（若有）。每个柱奖励在一局游戏中只触发一次。
- 柱奖励可能引起额外放置、翻面、释放囚徒等，这些操作均视为插入效果。

### 额外抽板与插入效果
- 鹦鹉、地图E第4列、地图G释放囚徒等都可能引起额外抽板或额外放置。
- 当插入效果发生时，先完成新触发的效果，再回到之前的流程。
- 释放囚徒时，该囚徒被放置到玩家选择的未满列最下方（不能翻面），放置后结算其当前正面角色效果。

### 藏宝图
- 藏宝图只有一张，初始不属于任何玩家。获得藏宝图时，所有权转移至该玩家（若已拥有则无事发生）。
- 藏宝图的效果：在每个**正式回合**完全结束后（所有插入效果结算完毕），拥有者获得1分。连续额外抽板的回合中，藏宝图只触发一次。

## 游戏结束与计分
- 当一名玩家填满至少4列时，游戏进入结束阶段：
  - 若后手玩家触发，则游戏立即结束。
  - 若先手玩家触发，则后手玩家再执行一个完整回合后游戏结束。
- 游戏结束后，进行终局计分：
  - **瞭望员**：每只上方无板块的瞭望员得4分。
  - **木匠**：每只所在行与列均无炮手的木匠得3分。
  - **水手**：设有n列包含水手，所有水手合计得n²分。
  - **鹦鹉**：每只鹦鹉扣1分。
  - **地图C特殊奖励**：第2列角色全部相同得6分；第4列角色互不相同得4分。
  - **炮手爆掉**：若某玩家地图上面朝上的炮手≥3个，该玩家直接输掉游戏。双方都爆掉则平局。

## 胜负判定
- 若一方爆掉，另一方获胜；双方都爆掉则平局。
- 若无人爆掉，比较总分，分高者获胜。
- 若总分相同，持有藏宝图的玩家获胜；若均无藏宝图则平局。
